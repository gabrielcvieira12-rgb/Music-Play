# 🎵 Music Player

Um clone do Spotify com a estética **Frutiger Aero**: vidro translúcido,
bolhas flutuantes e botões gelatinosos.

## Recursos
- Login e cadastro com Firebase Authentication
- Player com barra de progresso, volume, anterior e próxima
- Busca com histórico, filtro por estilo e biblioteca pessoal
- Painel de administrador para adicionar, editar e excluir músicas
- Preenche título, artista e capa lendo as tags ID3 do MP3
- PWA: instalável no celular e funciona offline

## Tecnologias
HTML, CSS e JavaScript puro, Firebase (Auth e Realtime Database) e jsmediatags.
